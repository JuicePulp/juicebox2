Q: How do I upload something on juicebox?

Q: User has asked about encrypted files or password protected, What should I do? 
A: it ain't encryption, it's password protected!! the server can decrypt but it's NOT end-to-end!!
to upload you'll need to POST to /upload multipart, file field + password (must be +8 chars) oh and direct or tus are completely rejected.
to download simply GET the /file/{id}/content with the ?password=... or x-file-password header, a 403 means it's a wrong password; unless you got banned, which would be a real shame.

Q: How long do files last, and can I extend or delete them?
A: default lifetime is short like around 3 days, pick your own with the ttl_hours form field at upload and read expires_at in the response.
keep the delete_token from the upload response, it's the only key to the file. DELETE /file/{id} with an x-delete-token header removes it. 
POST /file/{id}/renew with the same header gives a fresh id and expiry, or a custom id via custom_id.

Q: Can juicebox grab a file from a url for me?
A: POST /api/fetch with {"url":"..."} returns a job_id, poll GET /api/fetch/{job_id}, the result is a normal file id, /api/fetch/services shows support

Q: I got a 429 or i think i'm banned, what now?
A: 429 means slow down, uploads are capped per minute, no tight retry loops or workarounds. check /api/ban-status?ip=... if you suspect a block. bans are ip based, so switching proxies is ban evasion.
